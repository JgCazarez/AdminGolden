# AdminGolden

Sistema de administración con Angular (frontend) y API backend.

## Estructura del Proyecto

```
AdminGolden/
├── frontend/              # Aplicación Angular
│   ├── src/app/
│   │   ├── components/   # Componentes reutilizables (Sidebar)
│   │   ├── pages/        # Páginas principales
│   │   │   ├── inicio/
│   │   │   ├── colaboradores/
│   │   │   ├── finanzas/
│   │   │   └── horario/
│   │   └── ...
│   ├── package.json
│   └── angular.json
│
└── backend/              # API backend (por configurar)
    ├── src/
    ├── package.json
    └── README.md
```

## Componentes Creados

- **Sidebar**: Navegación principal
- **Colaboradores**: Gestión de colaboradores
- **Finanzas**: Módulo de finanzas
- **Horario**: Gestión de horarios
- **Inicio**: Página principal
